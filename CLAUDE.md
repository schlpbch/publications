## Repository Overview

This is a publications archive repository containing PDF files of academic papers spanning software composition/reengineering, handwriting recognition, document analysis, and LLM agentic systems. The repository consists entirely of academic publications with no source code, build system, tests, or code documentation.

## Repository Contents

PDFs are organized into folders by publication type:

- `preprints/` — arXiv preprints (2026 LLM agentic systems papers)
- `books/` — Book drafts (`MainLDAR.pdf`)
- `journal-articles/` — Journal papers (`ijprai2008.pdf`, `onlineWIJournal.pdf`, `journalPaperFinal.pdf`)
- `book-chapters/` — Book chapters (`offWriIdeVerGMM.pdf`)
- `conference-papers/` — Conference and workshop papers (ICPR, IWFHR, DAS, ICDAR, IGS, EUSIPCO; 2004–2008)
- `theses/` — Theses and technical reports (`Schl01a.pdf`, `Schl03a.pdf`)
- `presentations/` — Presentation slides (`iwfhr06Slides.pdf`)

## No Build, Test, or Development Commands

This repository has no:
- Build system or compilation requirements

- Source code to modify
